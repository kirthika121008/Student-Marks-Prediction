# Student Marks Prediction

## About
This is a beginner Python project that predicts student marks based on study hours.

## How it Works
- Enter the number of study hours.
- The program calculates predicted marks.
- Maximum predicted marks are limited to 100.

## Technologies Used
- Python

## How to Run
python marks_prediction.py

## Sample Output
Enter study hours: 5
Predicted Marks: 50.0
